# AIClientKit

Swift 6 with strict concurrency, macOS 27. Build/test with `swift build` and
`swift test`. Preserve provider Codable identities and stream metadata.

Public interfaces must be SDK-neutral and Sendable. Do not import an app,
AppKit, or SwiftUI. Inject configuration and credentials explicitly; do not
implicitly read Bundle.main, UserDefaults.standard, or app singletons.

The core product owns provider identity/request/event/model/credential contracts
and streaming coordination. AIClientHTTP owns explicit networking primitives;
AIClientOpenAICompatible owns the real custom-endpoint provider implementation.
AIClientModelDiscovery owns live catalog networking and decoding for Anthropic,
Gemini, Ollama, and Featherless; host titles and clients are explicit inputs.
Other provider implementations remain separate adoption slices. No placeholder networking.

AIClientAnthropic owns SDK-backed text requests, thinking/cache policy, projection,
and request-scoped sessions. SwiftAnthropic 2.2.2 is pinned to preserve the existing
wire behavior; its types stay internal. Host session configurations are copied,
and each operation owns its session. Never cancel a shared host URLSession.

AIClientOpenAI owns the characterized chat/Responses wire adapter, background
polling/cancellation, and the endpoint variants. It has no SDK dependency: the
untagged legacy SDK fork cannot be consumed beneath a package release. Fixture
bodies pin that fork's behavior; never regenerate them to accept regressions.
Model/preference policy arrives in explicit request profiles. Unknown response
statuses and payloads are retained. Remote cancellation is run-owned and single-use.

CI is generated by the CodeEditor superproject's Scripts/sync-package-ci.
